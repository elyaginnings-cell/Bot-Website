PUNISHMENT SYSTEM

Moderation

Warn tracking, auto escalation, and mod logs. Configure in Discord with the commands below.

Commands
  • /warn — Warn a user
  • /warnings — View warns
  • /unwarn — Remove a warn
  • /mute / /unmute
  • /kick / /ban
  • /set-warn-channel — Log channel
Auto escalation
  • 1 warn → Verbal Warning
  • 2 warns → Official Warning
  • 3 warns → Auto 10 min timeout
  • 4+ warns → Kick stage
Tips
  • Right-click a message → Apps → Warn User for auto evidence
  • Logs post as Coffee Shop | Moderation
  • Warns expire after 30 days
INVITE SYSTEM

Invites

Track who invited who, leaderboard, and automatic invite ranks.

Commands
  • /invites — Check stats
  • /invite-leaderboard
  • /invite-ranks — Rank list
  • /add-invites / /remove-invites
  • /set-invite-leaderboard
Invite ranks (auto roles)
  • 10 invites → rank role
  • 20 invites → rank role
  • 50 invites → rank role
Tips
  • Leaderboard auto-updates as Coffee Shop | Invites
  • Fake = accounts under 7 days old
  • Valid = regular + bonus − left − fake
LEVELING SYSTEM

Leveling

Members earn XP by chatting. Set level roles and the bot gives them automatically.

Commands
  • /rank — Check level & XP
  • /levels — Leaderboard
  • /set-level-role — Add reward
  • /remove-level-role
  • /level-roles — List rewards
  • /set-xp — Manual XP (admin)
How XP works
  • 15–25 XP per message
  • 1 minute cooldown
  • Level-up message in channel
  • Roles auto-applied at thresholds
Setup level roles
  • Use /set-level-role level:5 role:@Role
  • Repeat for each level you want
  • Bot needs Manage Roles
  • Roles must be below the bot
